# pair-wise-yf-52 戏剧排练台词版本与舞台提示管控

## 源提示词摘要
导演、编剧、舞台监督和演员共同维护不同版本的剧本、角色台词、上下场提示、道具与灯光音效提示。编剧提交后需逐条合并，演员可查看最新版并标记疑问；支持版本对比、单条采纳、批注、冲突处理、排练模式、大字号提词和断网缓存。

## 技术栈
Angular + TypeScript + Angular Material + NgRx + Angular Router + RxJS + Angular CDK + Transloco。

## 已实现闭环
- 剧本版本和导演修订的创建、切换与版本差异摘要。
- 角色台词、舞台提示的采纳、退回和待确认状态。
- 排练模式、在线/离线切换与 localStorage 持久化。
- 未确认内容保留在草稿版本中，不会自动混入已采纳版本。

## 巡演换场适配队列
巡演场剧本版本锁定（v12 🔒），换场只按剧场设备重核道具、灯光、音效提示：

- **台词锚点**：每条提示绑定台词 id + 文本指纹 + 锚点修订号；台词文本一改，相关提示立即变 `stale`，台词删除变 `missingAnchor`。重算后修订号 +1，各场馆旧确认全部作废，不会复活。
- **分场馆确认**：确认结果按 `场馆:提示` 分库保存，杭州、南京互不影响；南京演示缺少道具设备位。
- **设备核对**：确认时校验场馆是否具备对应设备（按设备序号 L-01/P-01/S-01 展示），缺设备或仍有失效锚点时排练提词门禁拦截，并列出全部原因。
- **岗位权限**：场务、舞台监督可按设备确认；导演只能覆盖失效/缺设备提示；编剧、演员越权操作一律拒绝并提示原因。
- **离线回执**：离线确认进入待传队列，回网自动**按设备序号排序合并**；同场馆/提示/指纹/设备的重复回执只入账一次；合并中途断网时未完成回执保留并累加重试次数，可断点续传；合并时锚点又变过的回执判 `anchor-drifted` 不再续传。
- **排练提词**：门禁全绿后进入大字号提词视图，仅展示已确认或导演覆盖的提示。
